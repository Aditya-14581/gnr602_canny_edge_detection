# Canny Edge Detection

This project implements the **Canny Edge Detection** algorithm using Python and PyQt5 for a graphical user interface (GUI). The application allows users to apply the Canny Edge Detection technique on images, with interactive threshold settings for edge detection.

## Project Overview

The Canny Edge Detection algorithm is used to identify the edges in images. It works by detecting areas of the image with sharp intensity gradients and marking them as edges. This project allows users to:

- Load an image to apply the Canny edge detection.
- Adjust the **low** and **high** thresholds using interactive sliders to control the edge detection sensitivity.
- Visualize the processed image for different values of the **sigma** parameter, which determines the Gaussian blur applied to the image.

## Features

- **Interactive Thresholds**: Adjust the lower and upper thresholds for edge detection using sliders.
- **Real-time Edge Detection**: See the results of the edge detection immediately after applying it to an image.
- **Sigma Adjustment**: View the edge detection results for different Gaussian blur levels (sigma values).
- **Simple GUI**: Built using PyQt5 for a user-friendly interface.
